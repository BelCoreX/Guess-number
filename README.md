# Игра "Угадай Число"

Целью игры является угадать конкретное число из диапозона чисел

## Планируется
- Добавить несколько режимов одиночной игры: обычный, на время, королевская битва
- Добавить соревновательный режим с другими игроками 
- Добавить достижения 
- Добавить графику
- Добавить магазин для кастомизации
